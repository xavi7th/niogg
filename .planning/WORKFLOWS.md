## 🌐 Public & Guest Journeys

### 1. Authentication & Onboarding

*   **Register:** User navigates to /register, fills name, email, password, clicks "Create Account", receives verification email, confirms, redirected to dashboard.
*   **Login:** User navigates to /login, enters email, password, clicks "Sign In", redirected to dashboard.
*   **Forgot Password:** User clicks "Forgot password?" on login page, enters email, clicks "Send Reset Link", receives email, follows link, sets new password.
*   **Reset Password:** User follows reset link /reset-password/{token}, enters new password, clicks "Reset Password", password updated, redirected to login.
*   **Verify Email:** After registration, user visits /verify-email, sees notice, clicks link in email (/verify-email/{id}/{hash}), email verified, redirected to dashboard.

### 2. Public Pages

*   **Home:** User visits /, sees landing page with overview.
*   **About Us:** User visits /about-us, reads company info.
*   **Vision & Values:** User visits /vision-and-values, reads mission.
*   **Careers:** User visits /career-opportunities, views job listings.
*   **Awards:** User visits /awards-and-recognitions, sees accolades.
*   **Gallery:** User visits /gallery, browses images.
*   **Contact:** User visits /contact-us, fills contact form, submits, receives thank‑you.
*   **Blog Index:** User visits /our-blog, reads list of articles.
*   **Blog Article:** User clicks article link, navigates to /article/{post}, reads content.
*   **Events Showcase:** User visits /events/media-showcase, sees event thumbnails.
*   **Event Detail:** User selects event, navigates to /events/{event:slug}, views details.
*   **Event Videos:** User clicks videos tab, navigates to /events/{event:slug}/videos, watches videos.

## 👤 Customer Journeys

### 3. User Dashboard & Profile

*   **Dashboard:** Authenticated user visits /user/dashboard, sees personalized overview.
*   **Edit Profile:** User navigates to /user/profile, updates name, email, clicks "Save", success notification.
*   **Update Password:** User visits password change page (via /user/profile), enters current and new password, clicks "Update", password changed.
*   **Delete Account:** User clicks "Delete Account" on profile page, confirms, account removed, redirected to home.

## 🛠️ Staff & Admin Journeys (Dashboard)

### 4. Admin Dashboard

*   **Dashboard:** Staff with admin role visits /admin/dashboard, sees metrics and shortcuts.

### 5. Event Management

*   **List Events:** Staff visits /admin/events, sees table of events.
*   **Create Event:** Staff clicks "Create", fills form, clicks "Save", new event appears in list.
*   **Edit Event:** Staff selects event, clicks "Edit", updates fields, clicks "Update", changes saved.
*   **Delete Event:** Staff selects event, clicks "Delete", confirms, event removed.
*   **Bulk Publish:** Staff selects multiple events, clicks "Publish", events become public.
*   **Bulk Unpublish:** Staff selects events, clicks "Unpublish", events hidden.
*   **Bulk Delete:** Staff selects events, clicks "Delete", confirms, events removed.

### 6. Video Management

*   **Upload Video:** Staff visits /admin/videos/upload/{event}, selects file, clicks "Upload", video added.
*   **Edit Video:** Staff clicks "Edit" on a video, updates title/description, clicks "Save".
*   **Reorder Videos:** Staff drags videos in list, clicks "Reorder", order saved.
*   **Upload Thumbnail:** Staff selects video, uploads custom thumbnail.
*   **Delete Video:** Staff clicks "Delete" on video, confirms, video removed.

## 🔑 Admin Journeys

### 7. User Management (Admins)

*   **Invite Staff:** Admin visits /admin/staff, clicks "Invite", enters email and role, sends invitation.
*   **Edit Staff Role:** Admin selects staff member, changes role/permissions, saves.
