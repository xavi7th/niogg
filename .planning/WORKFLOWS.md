## 🌐 Public & Guest Journeys

### 1. Authentication & Onboarding

*   **Register:** User navigates to /register, fills name, email, password, clicks "Create Account", receives verification email, confirms, redirected to dashboard.
*   **Login:** User navigates to /login, enters email, password, optionally checks "Remember me", clicks "Sign In", redirected to dashboard.
*   **Forgot Password:** User clicks "Forgot password?" on login page, enters email, clicks "Send Reset Link", receives email, follows link, sets new password.
*   **Reset Password:** User follows reset link /reset-password/{token}, enters new password, clicks "Reset Password", password updated, redirected to login.
*   **Verify Email:** After registration, user visits /verify-email, sees notice, clicks link in email (/verify-email/{id}/{hash}), email verified, redirected to dashboard.
*   **Confirm Password:** User accesses a sensitive action, is prompted to re-enter password at /confirm-password, confirms identity, proceeds with action.
*   **Logout:** Authenticated user clicks logout, session destroyed, redirected to home or login page.

### 2. Public Pages

*   **Home:** User visits /, sees hero slideshow with "Good Governance", "Transparent Leadership", "Institutional Collaborations" slides, browses features, about summary, initiatives, testimonials, partners, CTA sections, and featured blog articles. Can submit contact form directly from homepage.
*   **About Us:** User navigates to /about-us via header dropdown or homepage CTA, reads about NIOGG team, vision, mission, and values.
*   **Vision & Values:** User navigates to /vision-and-values via header dropdown, reads mission statement and core values.
*   **Careers:** User navigates to /career-opportunities via header dropdown, views available job listings.
*   **Awards:** User navigates to /awards-and-recognitions via header "News & Media" dropdown, sees accolades and recognition programs.
*   **Gallery:** User navigates to /gallery via header "News & Media" dropdown, browses event photos and images.
*   **Contact:** User navigates to /contact-us via header link, fills contact form (name, email, message), submits, receives thank-you notification.
*   **Blog Index:** User navigates to /our-blog via header "News & Media" dropdown, reads list of articles.
*   **Blog Article:** User clicks article link from blog index or homepage featured section, navigates to /article/{post}, reads content.
*   **Events Showcase:** User navigates to /events/media-showcase via header "News & Media" dropdown, sees event thumbnails grid.
*   **Event Detail:** User selects event from showcase, navigates to /events/{event:slug}, views event details, description, and timeline.
*   **Event Videos:** User clicks videos tab on event detail, navigates to /events/{event:slug}/videos, watches event videos.
*   **Conference Landing:** User navigates to /conferences/nigeria-leadership-quest-for-economy-growth, reads conference overview, watches promotional video, views speaker carousel, reads sponsor/exhibitor benefits. Can register via bank transfer (send receipt to phone) or fill reservation form (name, email, phone) and click "Register Now". Can click "Become a Sponsor" anchor to scroll to registration form.

## 👤 Customer Journeys

### 3. User Dashboard & Profile

*   **Dashboard:** Authenticated user visits /user/dashboard, sees personalized overview.
*   **Edit Profile:** User navigates to /user/profile (requires password confirmation), updates name, email, clicks "Save", success notification.
*   **Update Password:** User visits password change section on profile page, enters current and new password, clicks "Update", password changed.
*   **Delete Account:** User clicks "Delete Account" on profile page, confirms deletion, account removed, redirected to home.

## 🛠️ Staff & Admin Journeys (Dashboard)

### 4. Admin Dashboard

*   **Dashboard:** Staff with admin role visits /admin/dashboard, sees metrics and shortcuts to manage events, photos, and videos.

### 5. Event Management

*   **List Events:** Staff visits /admin/events, sees table of events with search and filter options.
*   **Create Event:** Staff clicks "Create", navigates to /admin/events/create, fills event form, clicks "Save", new event appears in list.
*   **View Event Detail:** Staff clicks an event in the list, navigates to /admin/events/{event}, views full event details and associated media.
*   **Edit Event:** Staff selects event, clicks "Edit", navigates to /admin/events/{event}/edit, updates fields, clicks "Update", changes saved.
*   **Delete Event:** Staff selects event, clicks "Delete", confirms, event removed.
*   **Bulk Publish:** Staff selects multiple events, clicks "Publish", events become public.
*   **Bulk Unpublish:** Staff selects events, clicks "Unpublish", events hidden.
*   **Bulk Delete:** Staff selects events, clicks "Delete", confirms, events removed.

### 6. Photo Management

*   **Upload Event Photos:** Staff navigates to an event detail page, uploads photos for the event via /admin/events/{event}/photos, photos appear in the event gallery.
*   **Reorder Event Photos:** Staff drags photos in the event photo list, clicks "Reorder", new order saved.
*   **Edit Photo:** Staff updates photo details (caption, title) via PUT /admin/photos/{photo}, saves changes.
*   **Delete Photo:** Staff clicks "Delete" on a photo, confirms, photo removed from event.
*   **Retry Thumbnail Generation:** Staff triggers thumbnail regeneration for a photo via POST /admin/photos/{photo}/retry-thumbnail, system regenerates the thumbnail.

### 7. Video Management

*   **Upload Video:** Staff visits /admin/videos/upload/{event}, selects video file, clicks "Upload", video added to event.
*   **Add Video via Event:** Staff navigates to /admin/videos/upload/{event} from event context, uploads video directly associated with the event.
*   **Edit Video:** Staff clicks "Edit" on a video at /admin/videos/{video}/edit, updates title/description, clicks "Save".
*   **Reorder Videos:** Staff drags videos in list, clicks "Reorder", order saved.
*   **Upload Thumbnail:** Staff selects video, uploads custom thumbnail via POST /admin/videos/{video}/thumbnail.
*   **Delete Video:** Staff clicks "Delete" on video, confirms, video removed.

## 🔑 Admin Journeys

### 8. User Management (Admins)

*   **Invite Staff:** Admin visits /admin/staff, clicks "Invite", enters email and role, sends invitation.
*   **Edit Staff Role:** Admin selects staff member, changes role/permissions, saves.
