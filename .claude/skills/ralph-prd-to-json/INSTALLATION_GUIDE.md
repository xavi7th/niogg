# Installation Guide: Ralph PRD to JSON Converter Skill

This guide walks you through installing the Ralph PRD to JSON Converter skill into your Claude Code project.

---

## Prerequisites

Before installing this skill, ensure you have:

1. **Claude Code CLI** installed and configured
2. A project with the **Ralph Wiggum autonomous development loop** set up (or you're setting one up)
3. The following directory structure exists in your project:
   ```
   your-project/
   ├── scripts/
   │   └── ralph/
   │       └── ralph.sh
   ├── tasks/
   │   └── (PRD files and prd.json will live here)
   └── .claude/
       └── settings.json
   ```

---

## Installation Steps

### Step 1: Create the Skills Directory

If you don't already have a skills directory in your project, create one:

```bash
mkdir -p .claude/skills/ralph-prd-to-json
```

### Step 2: Copy the Skill File

Copy `ralph-prd-to-json-skill.md` into your skills directory:

```bash
cp ralph-prd-to-json-skill.md .claude/skills/ralph-prd-to-json/SKILL.md
```

### Step 3: Verify Directory Structure

Ensure you have the required directories:

```bash
# Create tasks directory if it doesn't exist
mkdir -p tasks

# Create scripts/ralph directory if it doesn't exist
mkdir -p scripts/ralph
```

## Project Structure After Installation

Your project should look like this:

```

├── .claude/
│   ├── settings.json

│   └── archive/                          <-- Archived previous runs
└── ... (your project files)
```

## Usage

Once installed, you can trigger the skill by saying any of the following to Claude:

- "Convert PRD to JSON"
- "Generate prd.json"
- "Create ralph json"
- "PRD to json"
- "Prepare for ralph loop"
- "Convert this PRD"

### Input Modes

**Mode 1: Convert from File**
```
Convert tasks/prd-authentication.md to prd.json
```

**Mode 2: Convert from Text/Clipboard**
```
Convert this PRD to prd.json:

# My Feature
[paste PRD content here]
```

### Example Prompts

**Converting an existing PRD file:**
```
Convert the PRD to JSON for the Ralph loop
```

**Converting a specific PRD:**
```
Convert tasks/prd-user-authentication.md to prd.json
```

**Converting pasted content:**
```
Convert this PRD to prd.json:

# Task Status Feature
Add ability to mark tasks with different statuses...
```

## What the Skill Does

1. **Reads your PRD** — From `tasks/prd-*.md` or direct text input

2. **Archives previous work** — If `prd.json` exists with a different branch name, it's archived to `tasks/archive/`

3. **Checks testing infrastructure** — If `scripts/test.sh` or composer scripts are missing, adds a setup story (US-000)

4. **Generates user stories** — Converts functional requirements into properly sized, ordered stories

5. **Adds verification stories** — Automatically adds:
   - PEST test criteria for backend stories
   - Browser verification stories (-02) for UI changes
   - E2E test stories (-03) for complex workflows

6. **Outputs structured JSON** — Saves to `tasks/prd.json` ready for Ralph

---

## Context Isolation

This skill uses `context: fork`, meaning it runs as an isolated subagent. This keeps your main conversation context clean — you only receive the summary output, not the entire conversion process.

---

## Output Format

The skill generates a JSON file with this structure:

```json
{
  "project": "ProjectName",
  "branchName": "feature/feature-name",
  "description": "Feature description",
  "userStories": [
    {
      "id": "US-001",
      "title": "Story title",
      "description": "As a user, I want...",
      "acceptanceCriteria": ["Criterion 1", "Criterion 2"],
      "priority": 1,
      "passes": false,
      "notes": ""
    }
  ]
}
```

## Typical Workflow

1. **Create a PRD** (manually or using ralph-prd-generator skill):
   ```
   tasks/prd-my-feature.md
   ```

2. **Convert to JSON:**
   ```
   Convert the PRD to JSON
   ```

3. **Review the output:**
   ```
   ✅ Created tasks/prd.json

   Project: MyApp
   Branch: feature/my-feature

   Summary:
   - Total stories: 8
   - Main stories: 4
   - Browser verification stories (-02): 3
   - E2E test stories (-03): 1
   ```

4. **Run the Ralph loop:**
   ```bash
   ./scripts/ralph/ralph.sh 25
   ```

## Troubleshooting

### Skill Not Triggering

If Claude doesn't recognize the skill triggers:

1. Verify the skill file is in `.claude/skills/`
2. Check the file has the correct frontmatter (the `---` block at the top)
3. Restart your Claude Code session

### "No PRD file found" Error

If the converter can't find your PRD:

1. Ensure your PRD is saved in the `tasks/` directory
2. Ensure filename matches pattern `prd-*.md`
3. Try specifying the file directly: "Convert tasks/prd-my-feature.md to JSON"

### Missing Testing Infrastructure

If you see US-000 added to your stories, it means `scripts/test.sh` or composer scripts were missing. This is normal — Ralph will set these up first before processing other stories.

### Stories Too Large Warning

If the skill warns about large stories, consider:
- Breaking the PRD into smaller functional requirements
- Asking the skill to split: "Convert and split large stories"

## Uninstallation

To remove the skill:

```bash
rm .claude/skills/ralph-prd-to-json/SKILL.md
```

This only removes the skill. Your generated `prd.json` files and archives will remain intact.
