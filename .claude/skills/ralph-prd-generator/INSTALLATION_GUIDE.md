# Installation Guide: Ralph PRD Generator Skill

This guide walks you through installing the Ralph PRD Generator skill into your Claude Code project.

---

## Prerequisites

Before installing this skill, ensure you have:

1. **Claude Code CLI** installed and configured
2. A project with the **Ralph Wiggum autonomous development loop** set up (or you're setting one up)
3. The following directory structure exists in your project:
   ```
   your-project/
   ├── .claude/
   │   └── skills/
   │       └── ralph-prd-generator/
   │           ├── workflow-ralph-protocol.md
   │           └── SKILL.md
   ├── scripts/
   │   └── ralph/
   │       ├── ralph.sh
   │       └── prompt.md (will be created/updated by the skill)
   ├── tasks/
   │   └── (PRDs will be saved here)
   └── .claude/
       └── settings.json
   ```

---

## Installation Steps

### Step 1: Create the Skills Directory

If you don't already have a skills directory in your project, create one:

```bash
mkdir -p .claude/skills/ralph-prd-generator
```

### Step 2: Copy the Skill File

Copy `ralph-prd-generator-skill.md` into your skills directory:

```bash
cp ralph-prd-generator-skill.md .claude/skills/ralph-prd-generator/SKILL.md
```

### Step 3: Verify Directory Structure

Ensure you have the required directories:

```bash
# Create scripts/ralph directory if it doesn't exist
mkdir -p scripts/ralph

# Create tasks directory if it doesn't exist
mkdir -p tasks
```

### Step 4: Create Required Files (If Missing)

If you don't have the Ralph Wiggum loop files yet, create placeholder files:

```bash
# Create empty prompt.md (the skill will populate this)
touch scripts/ralph/prompt.md

# Create workflow protocol if you don't have one
touch .claude/skills/ralph-prd-generator/workflow-ralph-protocol.md
```

## Project Structure After Installation

Your project should look like this:

```
your-project/
├── .claude/
│   ├── settings.json
│   └── skills/
│       └── ralph-prd-generator/

├── scripts/
│   └── ralph/
│       ├── ralph.sh                         <-- Your autonomous loop script
│       └── prompt.md                        <-- Generated by skill
├── tasks/
│   ├── prd-[feature-name].md               <-- PRDs saved here
│   └── progress.txt                         <-- Progress tracking
└── ... (your project files)
```

## Usage

Once installed, you can trigger the skill by saying any of the following to Claude:

- "Create a PRD"
- "Write PRD for [feature name]"
- "Plan this feature"
- "Requirements for [project name]"
- "Spec out [feature]"
- "Convert issue to PRD"

### Example Prompts

**Starting a new project:**

```
Create a PRD for a new task management app
```

**Adding a feature to existing project:**

```
Write a PRD for adding user authentication to my app
```

**Converting a GitHub issue:**

```
Convert this GitHub issue to a PRD: https://github.com/user/repo/issues/123
```

## Configuration

### Model Selection

The skill uses lightweight models by default for cost efficiency. If you want to override this behavior, you can specify in your prompt:

```
Create a PRD for [complex feature] - use a higher-tier model for analysis
```

### Permissions

After the skill generates a PRD, it will review your `.claude/settings.json` and suggest permissions needed for autonomous development. You'll need to manually add these permissions.

Example suggestions the skill might make:

```json
{
  "permissions": {
    "allow": ["bun run dev", "bun run build", "bun run lint", "bunx prisma generate", "bunx prisma migrate dev"]
  }
}
```

## Troubleshooting

### Skill Not Triggering

If Claude doesn't recognize the skill triggers:

1. Verify the skill file is in `.claude/skills/`
2. Check the file has the correct frontmatter (the `---` block at the top)
3. Restart your Claude Code session

### Missing Directories Error

If the skill reports missing directories:

```bash
# Create all required directories
mkdir -p scripts/ralph tasks .claude/skills/ralph-prd-generator
```

### Permission Denied on ralph.sh

Make the script executable:

```bash
chmod +x scripts/ralph/ralph.sh
```

---

## Uninstallation

To remove the skill:

```bash
rm -rf .claude/skills/ralph-prd-generator/
```

This only removes the skill. Your generated PRDs and other files will remain intact.
